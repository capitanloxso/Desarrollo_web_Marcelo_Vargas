## Tarea 4

## Características

- Portada con últimos 5 avisos

- Agregar Aviso de Adopción

- Listado de Avisos de Adopción

- Estadísticas con 3 gráficos

- Sistema de comentarios para avisos

- Sistema de Evaluación de Avisos (Notas 1-7)

## Requisitos

- Usar venv

- Python instalado

- MySQL Server instalado

- pip install -r requirements.txt

- Java Development Kit (JDK) 17 o superior (Yo use el 17)

- Apache Maven

## Run con:
Hacer "cd Tarea4" en dos terminales, una para cada servidor.

Iniciar el Backend de Notas (Spring Boot):

Bash1 
cd backend-tarea4/
mvn spring-boot:run

Bash2
python app.py
